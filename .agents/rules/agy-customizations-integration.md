# Antigravity Customization Architecture & Lifetime Memory Integration

This rule enforces continuous learning, model memory alignment, and workspace customization management.

## 1. Universal Customization Enforcement
- **Root Authority**: Rules defined in `AGENTS.md` and `.agents/rules/*.md` are binding across all conversational turns and autonomous executions.
- **Continuous Knowledge Ingestion**: Whenever new templates, UI patterns, or architectural pipelines are developed, they must immediately be codified into `AGENTS.md` to train future model instances and eliminate redundant discovery.
- **Zero Redundant Work**: Always check local Knowledge Items (KI) and existing template implementations before creating new patterns from scratch.

## 2. Decision Protocol for Unspecified Requirements
Whenever the user's prompt leaves styling, 3D visual effects, layout geometry, or technical architecture underspecified:
1. **Apply `/web-design`**: Check layout rhythm, typography pairing, motion choreography, and anti-AI-slop heuristics.
2. **Apply `/ui-ux-pro-max`**: Select appropriate UI style, color physics, WCAG AAA contrast, and interactive micro-interactions.
3. **Apply `/agy-customizations`**: Maintain persistent documentation, register new components in registries and test suites, and ensure all tests pass.
