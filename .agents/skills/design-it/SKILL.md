# Design-It / Agentic Awesome Skills

## 1. Overview
Design-It focuses on creative art direction, aesthetic divergence, and visual diversity across generative web applications.

## 2. Creative Art Direction Philosophy
- **Aesthetic Universes**: Explore beyond dark developer terminals into Swiss Editorial, Brutalist Pop, Luxury Monochrome, Neo-Architectural, and Kinetic Spatial styles.
- **Structural Divergence**: Every interface composition should explore distinct spatial geometries (split-screen dossiers, asymmetric bento grids, editorial monographs, horizontal filmstrips, interactive terminal consoles).
- **Anti-Repetition Rule**: Reject identical visual combinations in sequential generations. Maintain a running structural memory across generation sessions.
