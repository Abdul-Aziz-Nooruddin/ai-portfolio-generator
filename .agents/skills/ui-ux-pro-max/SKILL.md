# UI/UX Pro Max Skill

## 1. Overview
UI/UX Pro Max provides data-backed design intelligence covering 84 distinct UI styles, 192 curated color palettes, 73 typography pairings, responsive UX rules, and anti-AI-slop guidelines.

## 2. Core Principles
- **No Generic Card Grids**: Avoid monotonous `<div>` card stacks with identical borders and icons.
- **Content-Driven Hierarchy**: Layouts must reflect actual content density and artifact depth rather than arbitrary templates.
- **Accessibility Baseline**: Enforce WCAG 2.2 AAA contrast standards (minimum 4.5:1 text-to-background) and explicit keyboard navigation states.
- **Semantic Motion**: Animations must reinforce spatial orientation, page flow, and content reveals rather than gratuitous decoration.
- **Zero AI-Slop**: Reject default purple/blue gradients, centered hero repetition, unmotivated glassmorphism, and floating decorative blobs.
