# Better Interface / Better UI Skill

## 1. Overview
Better Interface provides heuristic design critique rules for evaluating digital layouts, typographic rhythm, contrast ratios, and spatial balance.

## 2. Critique Criteria
1. **Typographic Rhythm**: Ensure harmonious scale ratios (1.25 Minor Third, 1.333 Major Third, 1.414 Augmented Fourth) with fluid `clamp()` formulas.
2. **Surface Physics**: Surfaces must establish clear depth layers without muddy shadows or excessive border borders.
3. **Information Density**: High-density engineering content should leverage structured metadata tables and syntax highlighting; narrative content should leverage expansive editorial columns.
4. **Touch & Keyboard Ergonomics**: Minimum 44x44px touch targets on mobile and high-visibility 2px focus rings for keyboard navigation.
