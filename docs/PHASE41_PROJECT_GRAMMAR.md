# 🏛️ Phase 41 — Within-Portfolio Project Grammar & Storytelling Diversity

## 1. Project Storytelling Grammar Systems

A portfolio featuring multiple projects must not render repetitive identical cards. 

Instead, the `ProjectStoryteller` dynamically assigns compatible artifact roles:
- **Lead Project**: `case-study-narrative`, `technical-dossier`, `fullscreen-interactive-slide`, or `terminal-session-log`.
- **Secondary Project**: `compact-metrics-table`, `split-screen-comparison`, `horizontal-filmstrip`, or `asymmetric-media-mosaic`.
- **Supporting Artifacts**: `repository-archaeology`, `before-after`, `failure-recovery`, `build-journal`, or `artifact-archive`.

---

## 2. Active Project Presentational Archetypes (14 Active)

1. `technical-dossier`: Full architectural specs, system topology diagrams, and trade-off tables.
2. `terminal-log`: Interactive CLI command buffer with execution status output.
3. `compact-metrics-table`: High-density telemetry rows with verified benchmark KPIs.
4. `horizontal-filmstrip`: Horizontally scrolling media gallery with snap alignment.
5. `magazine-editorial-chapter`: Multi-column editorial monograph chapter with inline drop caps.
6. `typographic-index-reveal`: Clean numbered index list with hover-triggered metadata reveal.
7. `asymmetric-media-mosaic`: Staggered bento grid with dynamic aspect ratios.
8. `case-study-narrative`: Deep prose essay with architecture callout sidebars.
9. `split-screen-comparison`: Side-by-side benchmark comparison.
10. `academic-research-paper`: LaTeX-styled academic paper citation and abstract block.
11. `build-journal`: Chronological engineering build log with timestamped commit notes.
12. `failure-recovery`: Incident postmortem layout detailing root cause analysis and mitigations.
13. `repository-archaeology`: Commit history breakdown and codebase evolution timeline.
14. `artifact-archive`: Numbered tabular archive with raw artifact links.
