# 🏛️ Phase 36: Rendering Authority Invariant & Verification

## 1. The Rendering Authority Invariant

The central invariant of Phase 36 is:

> **`CompositionPlan` is the single authoritative runtime contract for all visual and structural composition.**

### What `CompositionPlan` Authoritatively Owns:
1. **`pageTopology`**: Container geometry, grid/flex structure, margin rules, and full responsive `@media (max-width: 860px)` CSS.
2. **`navigationGrammar`**: Coordinate system, DOM position (top, sidebar, floating dock, anchor bar, header tabs), and interactive anchor points.
3. **`openingTopology`**: Semantic `<h1>` hero structure, lead typography scale, and viewport takeover mode.
4. **`sectionGrammar`**: Complete dynamic sequence array (`sequence`), whitespace distribution weights, and dynamic section morphing.
5. **`projectArtifactPlan`**: Multi-artifact presentation suite per project (e.g. `code-architecture-dossier`, `terminal-session-log`, `research-paper`).

---

## 2. Invalidation of Legacy Control Signals

The following legacy signals are strictly prohibited from independently controlling DOM rendering:
- ❌ Legacy template IDs (`template-1`, `template-5`, etc.)
- ❌ Hardcoded layout switch statements (`switch (layoutId)`)
- ❌ IA model ID branching (`if (iaModel.id === '...')`)
- ❌ Palette-driven structural layout decisions
- ❌ Universal default container assumptions (`max-width: 1200px; margin: 0 auto;`)

---

## 3. Runtime Enforcement via `CompositionAuthorityGate`

The `CompositionAuthorityGate` static and runtime architectural guard validates every portfolio generated by `SiteGenerator` and `DesignEngine`:

```javascript
const audit = CompositionAuthorityGate.audit(site);
if (!audit.pass) {
  throw new Error(`[COMPOSITION AUTHORITY VIOLATION] ${audit.violations.join(' | ')}`);
}
```

The gate automatically fails closed if:
1. `CompositionPlan` is missing from the result.
2. The rendered HTML does not contain the `pageTopology.rootClass`.
3. `sectionGrammar.sequence` is empty or missing.
4. Responsive mobile `@media` queries are omitted.
5. Legacy fallback template markers (`data-fallback-template="true"`) are detected.
