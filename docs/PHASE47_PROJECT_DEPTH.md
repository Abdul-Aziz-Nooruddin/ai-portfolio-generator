# 🏛️ Phase 47 Project Depth Scaling

## Project Presentation Tiers
Projects dynamically scale their visual and structural footprint based on evidence depth:

1. **`DEEP_CASE_STUDY` / `TECHNICAL_DOSSIER` (4+ Facts)**:
   - Features dedicated architecture blocks, throughput/latency metrics, challenges, and decision rationale callouts.
2. **`STANDARD_PROJECT` (2-3 Facts)**:
   - Clean balanced presentation featuring name, narrative description, technology stack, and live/repo links.
3. **`MICRO_ARTIFACT` (1 Fact)**:
   - Compact utility entry avoiding empty cards or padded whitespace.
