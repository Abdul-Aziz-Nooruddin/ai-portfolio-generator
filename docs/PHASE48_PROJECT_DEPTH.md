# 🏛️ Phase 48 Project Depth Scaling

## Project Hierarchy
Projects are categorized into 4 depth tiers:
1. **`DEEP_CASE_STUDY` (4+ Facts)**: Multi-column architectural blueprints, live telemetry clusters, challenge-decision-tradeoff matrices.
2. **`STANDARD_PROJECT` (2-3 Facts)**: Name, description, tech stack, and primary external links.
3. **`MICRO_ARTIFACT` (1 Fact)**: Clean minimal code snippet or single-link reference.
4. **`RESEARCH_ARTIFACT`**: Hardware benchmarks, DOI links, and algorithmic proofs.
