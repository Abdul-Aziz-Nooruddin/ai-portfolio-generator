# 🏛️ Phase 45 Content Allocation & Hierarchy Strategy

## Problem & Solution
- **The Anti-Pattern**: Attempting to force every fact into the hero or above the fold creates cluttered, illegible pages.
- **The Solution**: Content Allocation Hierarchy that routes primary signals to prominent positions while routing deeper specifications to structured dossiers, timelines, and technical appendices.

---

## 1. Information Tier Allocation

| Content Tier | Target Component Slot | Visual Presentation Mode |
| :--- | :--- | :--- |
| **Hero / Identity** | Primary Hero Masthead / Lateral Sidebar | Name, title, lead thesis, primary CTA, key contact links |
| **Selected Works** | Project Storyteller (Dossier / Slide / Runway) | Flagship project titles, descriptions, stack badges, demo buttons |
| **Deep Engineering Specs** | Project Case Study / Architecture Callout | Architecture patterns, performance metrics, challenges, tradeoffs |
| **Career Trajectory** | Narrative Timeline / Ledger / Monograph | Roles, companies, dates, responsibilities, outcomes, stack |
| **Academic & Research** | Research Strip / Academic Registry | Papers, venues, DOI links, abstracts, methodology, findings, coursework |
| **Supplementary Evidence**| Additional Evidence Appendix | Arbitrary custom fields, domain specifications, patents, grants, questionnaire statements |

---

## 2. Representation Without Duplication
Each fact receives **one primary representation** and optional contextual badges, preventing both data loss and unsightly repeated content.
