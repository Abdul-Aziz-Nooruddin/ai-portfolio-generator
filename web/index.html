Frequently Asked Questions

Everything you need to know about how AI Portfolio Studio generates and hosts your 3D portfolio.

❓ How does the Nano Banana 3D Engine create project images?

Instead of serving static placeholder JPGs, the Nano Banana engine synthesizes real-time 3D vector geometry tailored to each project's domain (e.g. Games, Neural Networks, UI Canvases, LeetCode Trees, Security Shields) with dynamic mouse look-at tilt physics.

🔒 Is my private GitHub code or personal data safe?

Yes, 100%. We only analyze public repository metadata (repo names, descriptions, languages, star counts) and documents you explicitly upload. We never access private repos or share personal data.

⏳ What happens when the 2-Hour free preview expires?

🌐 Can I link my own custom domain?

Yes! Pro subscribers can connect any custom domain (e.g. alexchen.dev or portfolio.yourbrand.com) directly through the User Dashboard with automated SSL certificate provisioning.

📦 Can I download the source code to host myself?

Yes. The Studio workspace provides a one-click Static ZIP Export containing clean HTML, CSS, JavaScript, and Three.js assets ready to deploy on Vercel, Netlify, or GitHub Pages.
